# Issue Tracker

- **Platform**: GitHub Issues (`ricardobizerra/skills`) via `gh` CLI.
- **Intake Policy**: All issues are evaluated against `SCOPE.md` (**Observed-Failure Bar**) and `.out-of-scope/`.
- **Labels**: `needs-triage`, `needs-info` (14-day stale close), `wontfix` (record rationale in `.out-of-scope/` when a recurring concept is rejected).
- **Pull Requests**: Restricted to maintainers and invited collaborators under the Curated Maintainer Model (`CONTRIBUTING.md`).
