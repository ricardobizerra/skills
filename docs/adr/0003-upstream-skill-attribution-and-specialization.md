# Upstream Skill Attribution and Governance Specialization

Several skills in this collection (`code-review`, `pr`, and `software-factory`) build upon foundational patterns created by Matt Pocock in `mattpocock/skills` and Dex Horthy in `humanlayer/skills` (`show-me`), while adding substantial authorial governance (default-branch immutability, protected verification path audits, canonical bracketed PR titles, 5-section Topic and Release PR templates, and rolling factory ratchets). Rather than maintaining silent forks or depending on external skill packages at runtime (which would break standalone installs via `skills.sh`), we decided to bundle self-contained, specialized versions of these skills inside `skills/engineering/` and attach explicit provenance via both YAML frontmatter (`metadata.credits`) and a dedicated `CREDITS.md` file inside each adapted skill directory.
